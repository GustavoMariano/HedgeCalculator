# Hedge Calculator

[English](README.md) | [Português](README.pt-BR.md)

A simple study project built with C#, WPF and .NET 10 to calculate how to distribute a bankroll between a main odd and a secondary odd.

The goal of the project is not to predict results, estimate probabilities or recommend bets. It is only a mathematical calculator that helps determine:

- the minimum secondary odd required for the main odd to still be profitable
- how much of the bankroll should be allocated to the main odd
- how much of the bankroll should be allocated to the secondary odd
- the possible return and profit in both scenarios

## Purpose

This project was created as a backend-focused study case.

The original idea was to keep all business logic inside a domain project and validate the behavior entirely through unit tests, without depending on a user interface.

After the core logic was complete, a very small WPF interface was added only to make the calculations easier to visualize and test manually.

## Important Disclaimer

This project is NOT:

- a betting recommendation tool
- a betting strategy generator
- a probability calculator
- a sports prediction system
- a guarantee of profit

The application does not analyze matches, teams, statistics, trends or real-world outcomes.

It only performs mathematical calculations based on the values entered by the user.

The user is fully responsible for choosing how to use the numbers generated by the application.

## Example Scenario

Suppose you have:

- Main odd: `1.35`
- Total bankroll: `100`

The application can calculate:

- the minimum secondary odd required so that the main odd can still generate profit
- how much should be allocated to each side
- the result if the main odd wins
- the result if the secondary odd wins

The secondary odd is designed to protect the bankroll, while the main odd remains the primary source of profit.

## Project Structure

```text
HedgeCalculator/
├── HedgeCalculator.Domain
│   ├── Services
│   └── Models
├── ProtectionCalculatorServiceTests
└── HedgeCalculator.Wpf
```

### HedgeCalculator.Domain
Contains all calculation logic and business rules.

### HedgeCalculator.Wpf
Small desktop interface built with WPF to enter values and display the calculation results.

### ProtectionCalculatorServiceTests
Unit tests written with xUnit to validate every calculation scenario.

## Main Features

- Calculate the minimum secondary odd
- Calculate the required bankroll split
- Show profit or loss for both scenarios
- Indicate whether the secondary odd fully protects the bankroll
- Simple and clean WPF interface
- Full unit test coverage for the calculation logic

## Running the Project

1. Clone the repository
2. Open the solution in Visual Studio 2022 or newer
3. Make sure .NET 10 SDK is installed
4. Set `HedgeCalculator.Wpf` as the startup project
5. Run the application

## Running the Tests

Open the Test Explorer in Visual Studio and run all tests, or execute:

```bash
 dotnet test
```
